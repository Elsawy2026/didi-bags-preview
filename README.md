# DODO BAGS - design preview

A non-saleable design demo with fictional bags, names, prices and stock. Browser-only changes, no real orders, payments, shipping or customer database. Do not enter real personal or payment details. Admin is an intentionally open, local-to-your-browser demonstration, not a production login.

This repository contains compiled presentation files only. Original source and data are not published here. The original live store is unchanged. The preview uses its own local storage namespace and does not overwrite earlier local project data.
